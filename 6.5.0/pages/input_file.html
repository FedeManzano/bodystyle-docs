Input File

Estilos y lógica provista por Bodystyle para mejorar la estética del componente nativo HTML <input type="file">.

Muestra

El estilo por default del componente, sin clases adicionales, es el siguiente:

 Información

Para utilizar este componente de inicialización automática es necesario disponer del archivo bodystyle.min.js agregado al proyecto, ya que la lógica de actualización del nombre del archivo seleccionado está implementada en JavaScript.

Colores

Con un sutíl cambio es posible modificar los colores del input file para adaptarlo al diseño del sitio web. En el siguiente ejemplo se utiliza la clase bg-red para cambiar el color de fondo del botón de selección de archivo.

Personalizado con color rojo 
    

        
        
        Personalizado con color rojo

Se recomienda utilizar las clases de color de Bodystyle para asegurar una correcta visualización y contraste entre el texto y el fondo del botón.
