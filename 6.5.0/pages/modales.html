Modales

Los modales son ventanas de diálogo que se superponen al contenido principal de la página web para mostrar información adicional o solicitar una acción por parte del usuario. En Bodystyle, los modales están diseñados para ser fáciles de usar y personalizar, permitiendo a los desarrolladores crear experiencias de usuario atractivas y funcionales.

Modal Simple

Ahora veremos un ejemplo de un modal simple, que contiene un título, un cuerpo de texto y un botón para cerrarlo.
Todos los modales son inicializados mediante una función provista por el objeto global BS.

💡 Tip: Los modales pueden ser cerrados presionando la tecla ESC o haciendo click en el fondo oscuro. Desde la versión 6.5.0 de Bodystyle incluye este elemento accesibilidad para mejorar la calidad e incluir a mas personas en su utilización.

Modal Confirmación

El tercer estilo predefinido es el modal de confirmación, que se utiliza para solicitar al usuario que confirme una acción antes de proceder. Este modal incluye un mensaje de confirmación y botones para aceptar o cancelar la acción.

Modal Scroll

Los modales en Bodystyle también soportan contenido desplazable. Si el contenido del modal excede la altura de la ventana, se habilitará una barra de desplazamiento dentro del cuerpo del modal para permitir al usuario navegar por el contenido.

 Información

Todos los modelos predefinos de modales pueden alterar o modificarse no son fijos, simplemente ejemplos y a través de las clases propuestas por bodystyle, el usuario podrá crear sus propios modales personalizados según sus necesidades.

Accesibilidad

♿ Características de Accesibilidad v6.5.0

  • Tecla Escape: Presiona ESC para cerrar cualquier modal
  • Navegación con Teclado: Usa Tab para navegar entre elementos
  • Focus Visible: Los elementos tienen outline azul cuando tienen focus
  • Atributos ARIA: Soporte completo para lectores de pantalla
  • Botón de Cerrar Accesible: El botón X funciona con click, Enter y Espacio
  • Gesión de Focus: El focus se restaura al elemento que abrió el modal
  • Roles Semánticos: Estructura WCAG 2.1 compliant
