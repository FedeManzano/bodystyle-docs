💎 Efecto 3D

Efecto en CSS que permite girar un elementos y mostrarlo de diferentes ángulos y mostrar el movimiento del elementos en 3D.

Muestra

Nótese que el contenedor principal del efecto 3D es .contenedor-efecto3d, y dentro de este se encuentra el contenedor vertical .contenedor-vertical que contiene las dos caras del elemento: la cara delantera .adelate y la cara trasera .atras-vertical.
La biblioteca provee dos efectos 3D: En uno el elemento gira sobre un eje vertical y en otro sobre un eje horizontal.

 Estructura

Clases Disponibles

A continuación se encuentran todas las clases CSS disponibles para implementar el efecto 3D:

Clase Descripción Obligatoria
.contenedor-efecto3d Contenedor principal que envuelve todo el efecto 3D
.contenedor-vertical Contenedor que hace girar el elemento sobre un eje vertical (izquierda-derecha) Sí (o usar horizontal)
.contenedor-horizontal Contenedor que hace girar el elemento sobre un eje horizontal (arriba-abajo) Sí (o usar vertical)
.adelate Define la cara delantera del elemento que se muestra al inicio
.atras-vertical Define la cara trasera del elemento en un efecto vertical Si usa vertical
.atras-horizontal Define la cara trasera del elemento en un efecto horizontal Si usa horizontal

Variaciones del Efecto

Existen diferentes variaciones del efecto 3D que puedes utilizar para obtener diferentes resultados. A continuación se muestran algunas variaciones comunes con diferentes velocidades y estilos de animación.

 Efecto Lento (2 segundos)

Un efecto más suave y elegante, ideal para elementos que requieren una transición gradual.

Efecto Lento

Duración: 2 segundos

Detrás

Pasa el ratón sobre la tarjeta

    &:hover .contenedor-vertical {
        transform: perspective(600px) rotateY(180deg);
        transition: transform 2s ease-in-out;
    }

 Efecto Rápido (0.5 segundos)

Un efecto ágil y dinámico, perfecto para interacciones rápidas.

Efecto Rápido

Duración: 0.5 segundos

Detrás

Pasa el ratón sobre la tarjeta

    &:hover .contenedor-vertical {
        transform: perspective(600px) rotateY(180deg);
        transition: transform 0.5s ease-in-out;
    }

 Efecto Elasticity (1.2 segundos)

Un efecto con rebote, que simula una animación más elástica y divertida.

Efecto Elástico

Duración: 1.2 segundos

Detrás

Pasa el ratón sobre la tarjeta

    &:hover .contenedor-vertical {
        transform: perspective(600px) rotateY(180deg);
        transition: transform 1.2s cubic-bezier(0.68, -0.55, 0.265, 1.55);
        /* Este cubic-bezier crea un efecto de rebote */
    }

 Perspectiva Profunda

Variación del efecto con una perspectiva más profunda (300px en lugar de 600px) para un efecto más dramático.

Perspectiva Profunda

Efecto más dramático

Detrás

Pasa el ratón sobre la tarjeta

    &:hover .contenedor-vertical {
        transform: perspective(300px) rotateY(180deg);
        /* Una perspectiva menor (300px) crea un efecto más pronunciado */
        transition: transform 1s ease-in-out;
    }

 Información

Puedes personalizar el efecto ajustando:

  • transition: Cambia la duración (ej: 0.5s, 1s, 2s, etc.)
  • easing function: Modifica ease-in-out por ease, linear, ease-in, ease-out o cubic-bezier()
  • perspective: Reduce el valor para un efecto más dramático, aumenta para menos dramático
  • rotateX/rotateY: Cambia el ángulo (ej: 90deg, 270deg, etc.)

Sass

Para entender como funciona el efecto 3D en Sass, veamos las variables y mixins utilizados: 

    &:hover .contenedor-vertical {
        transform: perspective(600px) rotateY(180deg);
        -webkit-transform: perspective(600px) rotateY(180deg);
        -moz-transform: perspective(600px) rotateY(180deg);
        -o-transform: perspective(600px) rotateY(180deg);
        -webkit-box-shadow: 0px 0px 14px 4px rgba(117, 117, 117, 0.71);
        -moz-box-shadow: 0px 0px 14px 4px rgba(117, 117, 117, 0.71);
        box-shadow: 0px 0px 14px 4px rgba(117, 117, 117, 0.71);
    }

    &:hover .contenedor-horizontal {
        transform: perspective(600px) rotateX(180deg);
        -webkit-transform: perspective(600px) rotateX(180deg);
        -moz-transform: perspective(600px) rotateX(180deg);
        -o-transform: perspective(600px) rotateX(180deg);
        -webkit-box-shadow: 0px 0px 14px 4px rgba(117, 117, 117, 0.71);
        -moz-box-shadow: 0px 0px 14px 4px rgba(117, 117, 117, 0.71);
        box-shadow: 0px 0px 14px 4px rgba(117, 117, 117, 0.71);
    }

 Información

El efecto 3D se logra mediante la propiedad CSS transform junto con la función perspective y las rotaciones rotateY para el efecto vertical y rotateX para el efecto horizontal. Al aplicar el efecto, se añade una sombra al contenedor para mejorar la percepción de profundidad.
