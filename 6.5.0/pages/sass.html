🎨 Sass

Bodystyle utiliza Sass para facilitar la personalización y el mantenimiento del código CSS. Sass es un preprocesador CSS que permite utilizar variables, anidamiento, mixins y otras funcionalidades que no están disponibles en CSS puro. Esto hace que el desarrollo de estilos sea más eficiente y organizado.

Instalación y Uso

Para utilizar las funcionalidades avanzadas de Sass en Bodystyle, necesitas tener Sass instalado en tu proyecto. Aquí te mostramos los pasos para comenzar:

Instalación

Si aún no tienes Sass instalado, puedes hacerlo a través de npm:

npm install -g sass
# o instalarlo localmente en tu proyecto
npm install --save-dev sass

Configuración en tu Proyecto

Una vez instalado Sass, puedes importar las variables, funciones y mixins de Bodystyle en tus archivos Sass: 

// En tu archivo main.scss
@use "sass:map";

// Importar las variables de Bodystyle
@use "ruta/a/bodystyle/sass/variables" as *;
@use "ruta/a/bodystyle/sass/funciones" as *;
@use "ruta/a/bodystyle/sass/mixins" as *;

// Ahora puedes usar las variables, funciones y mixins
.contenedor {
    background-color: $fd-azul;
    @include flex-box-centrado();
}

Compilar Sass a CSS

Para compilar tus archivos Sass a CSS, utiliza el siguiente comando: 

// Compilar un archivo específico
sass input.scss output.css

// Monitorear cambios (watch mode)
sass --watch .

// Compilar con opciones de producción (comprimido)
sass --style=compressed input.scss output.css

Funciones

Bodystyle incluye una serie de funciones Sass que facilitan la manipulación de colores, tamaños y otros valores. Estas funciones permiten realizar cálculos y transformaciones directamente en el código Sass, lo que simplifica la creación de estilos dinámicos y adaptativos. 

    /**
        Todas estas funcionalidades aectan a toda la biblioteca BodyStyle 
        Para comprender el funcionamiento existe un archivo de variables donde se
        definen los mapas y variables globales.
    */
    @use "sass:map";
    @use "variables";

    ////
    /// @group Funciones
    /// Funciones de la libreria bodyStyle v2.0.0
    ////

    /// Función que devuelve el tamaño de letra para una etiqueta html predefinida en la variable $letras.
    /// @param {Map} $hashLetras - Mapa de tamaños de letras
    /// @param {String} $etiqueta - Etiqueta HTML (h1, h2, etc.)
    /// @return {Number} Tamaño de fuente
    @function tamLetra($hashLetras, $etiqueta) {
        @if(map.has-key($hashLetras, $etiqueta )) {
            @return map.get($hashLetras , $etiqueta);
        }

        @else {
            @warn "La etiqueta html no existe";
        }
    }

    /// Función para establecer el grosor de las Fuentes
    /// @param {Map} $grosor - Mapa de grosores
    /// @param {String} $val - Clave del grosor
    /// @return {Number} Valor del grosor
    @function get-grosor($grosor, $val) {
        @if(map.has-key($grosor, $val )) {
            @return map.get($grosor , $val);
        }

        @else {
            @warn "El grosor seleccionado no existe";
        }
    }


    /// Función que devuelve el nivel del componente (z-index)
    /// @param {String} $al - Nombre del nivel de superposición
    /// @return {Number} Valor z-index
    @function superposicion($al) {
        @if map.has-key(variables.$superposicion, $al) {
            @return map.get(variables.$superposicion, $al);
        }

        @else {
            @warn "El componente no existe";
        }
    }

    /// Devuelve el breakpoint
    /// @param {String} $med - Clave del tamaño (xs, s, m, l, xl)
    /// @return {Number} Valor del breakpoint
    @function dameMedida($med) {
        @if map.has-key(variables.$tamaños, $med) {
            @return map.get(variables.$tamaños, $med);
        }
    }

    /// Verifica si un valor es múltiplo de 5
    /// @param {Number} $num - Número a verificar
    /// @return {Boolean} True si es múltiplo de 5
    @function multiplo5($num) {
        @return $num % 5==0;
    }

    /// Inicializa una variable en 0
    /// @return {Number} 0
    @function inicializarVariable() {
        @return 0;
    }

    /// Incrementa una variable en 0.5
    /// @param {Number} $var - Variable a incrementar
    /// @return {Number} Variable incrementada
    @function incrementar($var) {
        @return $var + 0.5;
    }

Mixins

Bodystyle también incluye una serie de mixins Sass que permiten reutilizar bloques de código CSS en diferentes partes del proyecto. Los mixins son especialmente útiles para aplicar estilos comunes a múltiples elementos sin duplicar el código. 

    @use "sass:map";
    @use "funciones";
    @use "variables";

    ////
    /// @group Mixins Generales
    /// Utilidades para media queries y layout
    ////

    /// Aplica estilos para pantallas menores a un tamaño específico
    /// @param {String} $tam - Clave del mapa de tamaños (xs, s, m, l)
    @mixin agregar-a-medida-maxima($tam) {
        @if map.has-key(variables.$tamaños, $tam) {
            @media (max-width: #{map.get(variables.$tamaños, $tam)}) {
                @content;
            }
        }

        @else {
            @warn "El tamaño seleccionado no existe";
        }
    }

    ;

    /// Aplica estilos para pantallas mayores a un tamaño específico
    /// @param {String} $tam - Clave del mapa de tamaños (xs, s, m, l)
    @mixin agregar-a-medida-minima($tam) {
        @if map.has-key(variables.$tamaños, $tam) {
            @media (min-width: #{map.get(variables.$tamaños, $tam)}) {
                @content;
            }
        }

        @else {
            @warn "El tamaño seleccionado no existe";
            ;
        }
    }

    ;

Mejores Prácticas

Para maximizar la eficiencia y mantenibilidad de tu código Sass con Bodystyle, te recomendamos seguir estas mejores prácticas:

1. Organización de Archivos

Estructura tus archivos Sass de manera lógica y jerárquica: 

sass/
├── main.scss                 # Archivo principal
├── variables/
│   ├── _colores.scss
│   ├── _tipografia.scss
│   └── _espaciado.scss
├── mixins/
│   ├── _flexbox.scss
│   ├── _media-queries.scss
│   └── _botones.scss
├── componentes/
│   ├── _cards.scss
│   ├── _formularios.scss
│   └── _navegacion.scss
└── utilidades/
    └── _helpers.scss

2. Nomenclatura de Variables

Usa nombres descriptivos y consistentes para tus variables. Bodystyle utiliza el patrón de nombrado que puedes seguir: 

// ✅ Buen nomenclatura
$color-primario: #1045B7;
$espaciado-base: 1rem;
$breakpoint-tablet: 770px;
$transicion-rapida: 0.3s ease;

// ❌ Evita nombres genéricos o poco claros
$c1: #1045B7;
$sp: 1rem;
$bp-m: 770px;

3. Uso de Mapas para Colecciones

En lugar de crear múltiples variables, agrupa valores relacionados en mapas: 

// ✅ Mejor: Usar mapas
$colores: (
    "primario": #1045B7,
    "secundario": #00C7A4,
    "error": #E41616,
    "exito": #009C80
);

// Acceder a los valores
.boton-primario {
    background-color: map.get($colores, "primario");
}

// ❌ Menos organizado: Variables individuales
$color-primario: #1045B7;
$color-secundario: #00C7A4;
$color-error: #E41616;

4. Evitar Anidamiento Excesivo

Aunque Sass permite anidamiento profundo, es importante mantener una jerarquía razonable para mantener el código legible: 

// ✅ Anidamiento moderado (máx 3-4 niveles)
.tarjeta {
    padding: 1rem;
    background-color: white;

    .tarjeta-header {
        border-bottom: 1px solid #ddd;

        h3 {
            margin: 0;
            color: map.get($colores, "primario");
        }
    }
}

// ❌ Anidamiento excesivo (difícil de leer)
.tarjeta {
    .tarjeta-header {
        .titulo {
            .subtitulo {
                .contenido {
                    color: red; // Muy profundo!
                }
            }
        }
    }
}

5. Reutilizar Mixins en lugar de Duplicar Código

Aprovecha los mixins de Bodystyle para evitar duplicación de estilos: 

// ✅ Usar mixins disponibles
.contenedor-centrado {
    @include flex-box-centrado();
    padding: 2rem;
}

.boton-personalizado {
    @include inicializar-botones();
    @include btn-colores(#1045B7, white, 18px);
}

// Responsive design con mixins
.elemento {
    font-size: 1.5rem;
    
    @include agregar-a-medida-maxima(s) {
        font-size: 1.2rem;
    }
}

6. Comentar el Código Importante

Usa comentarios para documentar secciones complejas o decisiones de diseño: 

// ========================================
// Componente: Tarjeta de Producto
// ========================================
// Define los estilos para las tarjetas
// utilizadas en la página de productos.

.producto-tarjeta {
    @include ancho-alto(100%, auto);
    
    // Efecto hover: elevar tarjeta
    &:hover {
        box-shadow: 0 8px 16px rgba(0, 0, 0, 0.2);
        transform: translateY(-4px);
    }
}

7. Validar Variables Antes de Usarlas

Bodystyle incluye funciones que validan si un valor existe en un mapa. Úsalas para evitar errores: 

// Verificar si existe un breakpoint
@if map.has-key(variables.$tamaños, "s") {
    @media (max-width: map.get(variables.$tamaños, "s")) {
        // Estilos para pantallas pequeñas
    }
}

// Usar función para obtener z-index seguro
.menu {
    z-index: superposicion(ms); // Retorna 100000 de forma segura
}

8. Evitar !important

Estructura tu CSS de manera que rara vez necesites !important. Si lo necesitas frecuentemente, revisa tu especificidad: 

// ✅ Mejor: Mayor especificidad
.contenedor .boton.boton-primario {
    background-color: #1045B7;
}

// ❌ Evita:
.boton {
    background-color: #1045B7 !important;
}
