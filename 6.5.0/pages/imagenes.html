🖼️ Imágenes

En este apartado veremos las clases y funciones de JS para el manejo de imágenes en Bodystyle.

Display

Clases utilitarias que se utilizan para imágenes cuadradas o circulares.
Permiten definir un ancho y alto multiplo de ocho para los contenedores de las imágenes.

 Información

Los displays permiten crear contenedores que van desde 8 PX a 800px siempre cuadrados, no funcionan para imágenes rectangulares.

 Circular

Podemos disponer de imágenes cirsulares utilizando las clases de Bordes de Bodystyle.

Zoom

Bodystyle dispone de una funcionalidad para realizarle Zoom a una imágen de manera tan que el usuario pueda verla en pantalla completa, para esta tarea es necesario inicializar el módulo corresponsiente de JS. 

    

        
        
    


    // Es necesario inicializar el módulo de imágenes para que funcione el zoom
    BS.ImagenesInit();

Paralax

Bodystyle incluye un módulo de JS que permite generar el efecto paralax en las imágenes de fondo de los contenedores, para ello es necesario inicializar el módulo correspondiente. 

    

        
        

            
            
        

    


    // Es necesario inicializar el módulo de paralax para que funcione el efecto
    BS.ParalaxInit();
