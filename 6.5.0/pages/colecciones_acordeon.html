     BS.Colecciones() // Devuelve una instancia del componente Colecciones
        .iniciar(
        {    
            contexto : "#coleccion_desplegable", // Contexto de inicialización
            colorFondo : "bg-pink-d-1",          // Color de fondo de los ítems desplegables
            colorTexto : "c-blanco",             // Color del texto de los ítems desplegables
            colorFlechas : "#fff"                // Color de las flechas de los ítems desplegables
       })
Parámetro Tipo Descripción
contexto string Selector CSS que define el contenedor principal de la colección desplegable.
colorFondo string Clase de Bodystyle que define el color de fondo de los ítems desplegables.
colorTexto string Clase de Bodystyle que define el color del texto de los ítems desplegables.
colorFlechas string Color en formato hexadecimal que define el color de las flechas de los ítems desplegables.

Destroy

Como todos los módulos de Bodystyle, las colecciones desplegables cuentan con un método destroy que nos permite eliminar la funcionalidad del componente en cualquier momento. 

    // Método Destroy para eliminar las colecciones desplegables
    const Destroy = () => {

        // Se crea una instancia de colecciones
        const col = BS.Colecciones();

        // Se eliminan las colecciones desplegables por su contexto
        col.destroy("#coleccion_desplegable");
        col.destroy("#tablas_desplegable");
        col.destroy("#ejemplo_completo");
        BS.Toast({
            html: "⭐ Se han eliminado las colecciones desplegables.",
        })
    }
