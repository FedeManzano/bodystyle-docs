🔖 Tabs

El componente Tabs permite organizar y mostrar contenido en secciones separadas dentro de una misma área de la página web. Cada pestaña (tab) representa una sección diferente de contenido, y los usuarios pueden cambiar entre ellas haciendo clic en las pestañas correspondientes. Esto es útil para mejorar la experiencia del usuario al permitirle acceder rápidamente a diferentes conjuntos de información sin necesidad de cargar nuevas páginas.

Inicialización

En este caso es un componente configurable, lo cual en un principio es un poco más complicado su uso, a través de la función de inicialización obtendremos una instancia del tab, la cual a través de parámetros especícos podremos configurar su comportamiento.

Parámetros

Como se mencionó anteriormente este componente es conpletamente configurable, para esto es necesario pasarle parámetros a la función de inicialización. A continuación se detallan.

Parámetro Tipo Descripción
contexto string Selector CSS que apunta al contenedor principal del tab. Este parámetro es obligatorio para que el componente funcione correctamente.
colorFuente Clase con el color de la fuente Clase CSS que define el color de la fuente para el tab.
colorFondo Clase con el color de fondo Clase CSS que define el color de fondo para el tab.
colorBorde Clase con el color del borde selector Clase CSS que define el color del borde para el tab.

Destroy

Es posible destruir los tabs desvinculado la lógica de JS del componente específico para esta tarea se tomará una instancia del tab y llamaremos al método destroy pasándole el contexto del tab a destruir. 

    const Destroy = () => {
        // Tomar una instancia del tab
        const tabInstances = BS.TabInit();

        // Luego a través de ella llamar al método destroy pasándole el contexto del tab a destruir
        tabInstances.destroy("#tab1");
        tabInstances.destroy("#tab2");
        tabInstances.destroy("#log-reg");
        BS.Toast({
            html: "✅ Todos los Tabs han sido destruidos.",
        })
    }

Desactivado

Es posible anular momentaneamente la funcionalidad de los tabs si se desea, para ello solo le añadimos la clase .desactivado y listo!, el tab no funcionará y se mostrará comop desactivado, cuando esta clase sea removida el tab volverá a funcionar normalmente.
