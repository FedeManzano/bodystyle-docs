🗺️ Navegación

En este apartado veremos la barra de navegación principal de Bodystyle.
La barra de navegación es un componente fijo que se encuentra en la parte superior de la página y permite al usuario navegar por las diferentes secciones de la documentación de Bodystyle.

La clase utilizada para esto es .bs-nav-fixed.

Cosas Importantes: Es necesario que el atributo data-target del nav apunte al ID del sidebar que se desea desplegar y es necesario respetar el caracter # al inicio del valor del atributo.

Destroy

Para destruir el componente de navegación y eliminar los eventos asociados se utiliza el siguiente método: 

    const Destroy = () => {
        BS.NavigationDestroy();
        BS.Toast({
            html: "✅ Navigation Destroyed",
            duracion: 3000
        })
    }
