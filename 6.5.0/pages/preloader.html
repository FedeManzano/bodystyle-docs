Preloader

Componente Preloader para indicar al usuario que un proceso está en curso.
Utilizado comúnmente durante la carga de páginas o la espera de respuestas del servidor.

Muestra

Ahora veremos una muestra de este sencillo elemento que funciona solo con CSS.

Colores

Existe una paleta de colores para estos elementos que permite adaptarlos a cualquier diseño.

Combinados

Es posible utilizar estos elementos combinados con otros, por ejemplo: Botones. 

    

    

        
        
    


    const Activar = () => {
        const btn = document.getElementById("btn-loader");
        btn.classList.remove("desactivado");
        btn.querySelector(".preloader-sm").remove();
        btn.innerHTML = `Click Me!`;
    }

    const Desactivar = () => {
        const btn = document.getElementById("btn-loader");
        btn.classList.add("desactivado");
        btn.innerHTML = ` Cargando...`;
    }
