📖 Ejemplo: Buscador Integrado

✨ Este ejemplo muestra cómo integrar el buscador en las páginas de documentación.

Prueba escribiendo en el buscador de arriba para ver cómo funciona.

🎯 Características

  • ✅ Búsqueda no-bloqueante (Web Worker)
  • ✅ Resultados ordenados por relevancia
  • ✅ Debounce automático (300ms)
  • ✅ Indicador visual de carga
  • ✅ Integración simple

📝 Implementación

1. HTML (Input)

<div class="busqueda-container mb-3">
    <div class="input-g ancho-50">
        <div class="grupo">
            <span class="span-grupo">🔎</span>
            <input type="search" data-buscar placeholder="Buscar...">
            <div class="indicador-carga" data-cargando>
                <span class="spinner"></span>
            </div>
        </div>
    </div>
    <div class="resultados-container" data-resultados></div>
</div>

2. JavaScript (Inicialización)

// Definir índices
const indicesBusqueda = [
    { title: "Botones", url: "botones.html", tags: ["botones", "btn"] },
    { title: "Colores", url: "colores.html", tags: ["colores"] },
    { title: "Grid", url: "grid.html", tags: ["grid", "layout"] }
];

// Inicializar
window.BuscadorModule.Init(indicesBusqueda);

3. CSS (Estilos básicos)

Ver archivo css/docs.css para estilos completos.
