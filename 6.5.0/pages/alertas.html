Alertas

Las alertas son componentes visuales utilizados para informar a los usuarios sobre eventos importantes, advertencias o errores en una interfaz de usuario. Su objetivo principal es captar la atención del usuario de manera efectiva y transmitir mensajes cruciales de forma clara y concisa.

Tema Light

La biblioteca provee dos temas predefinidos: Light y Dark. A continuación se muestran ejemplos de alertas utilizando el tema Light con diferentes variantes de colores y estilos.

Tipos de Alertas Disponibles

El tema Light proporciona 6 tipos de alertas diferenciadas por color, cada una optimizada para transmitir un mensaje específico al usuario:

  • Alerta Roja (.bs-alert-red): Utilizada para mensajes de error, advertencias críticas o acciones destructivas
  • Alerta Azul (.bs-alert-blue): Destinada a información general, mensajes informativos o datos importantes
  • Alerta Amarilla (.bs-alert-yellow): Ideal para advertencias, avisos o situaciones que requieren atención del usuario
  • Alerta Blanca (.bs-alert-white): Utilizada para mensajes neutros o de carácter general
  • Alerta Gris (.bs-alert-gray): Para información secundaria o contenido menos relevante
  • Alerta Verde (.bs-alert-green): Reservada para mensajes de éxito, confirmaciones o acciones completadas

Características del Tema Light

El tema Light de las alertas posee las siguientes características de diseño:

  • Fondos claros y semi-transparentes para mejor integración con el fondo blanco
  • Bordes sutiles de color que ayudan a identificar el tipo de alerta
  • Sombras suaves que proporcionan profundidad sin ser invasivas
  • Texto oscuro para máxima legibilidad en pantallas claras
  • Tipografía clara con separación entre título y contenido
  • Animaciones suaves al pasar el cursor (hover) para mayor interactividad

Como se puede observar en los ejemplos anteriores, las alertas están diseñadas para resaltar mensajes importantes utilizando diferentes colores y estilos según el tipo de alerta (roja, azul, amarilla, blanca, gris y verde) todos ellos pertenecientes al tema Light. Cada color tiene un propósito específico dentro de la experiencia del usuario.

Tema Dark

Al igual que el tema Light, la biblioteca también ofrece un tema Dark para las alertas. A continuación se muestran ejemplos de alertas utilizando el tema Dark con diferentes variantes de colores y estilos.
La diferencia es que en vez de envoltarlas en un div con la clase .bs-alert-light, se envuelven en un div con la clase .bs-alert-dark, luego en ambos temas contamos con las mismas alertas: .bs-alert-red, .bs-alert-blue, .bs-alert-yellow, .bs-alert-white, .bs-alert-gray y .bs-alert-green.
