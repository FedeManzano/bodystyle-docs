⬆️ Sidebar Dropdown

Componente Sidebar con elementos desplegables asociado al nav principal para mejorar la navegación en la página.
Componente complementario al nav para brindarle al usuario un conjunto superior de opciones.
Este componente es ideal para sitios web con muchas secciones o categorías, ya que permite organizar el contenido de manera eficiente y accesible.

Tema Oscuro

Al igual que en el ejemplo anterior Bodystyle porvee un tema oscuro para este componente, mas alla de esto el usuario puede personalizar los colores a su gusto utilizando las clases de colores de Bodystyle.

Sidebar Dark

En este caso solo cambia la clase del sidebar de (bs-sidebar-drop-light) a (bs-sidebar-drop-dark) para lograr el efecto deseado.

Submenú

En la mayoría de los casos es necesario que cuando el usuario ingresa a la página el submenú en el cual se encuentre en ese momento esté desplegado, orientando al usuario sobre su ubicación dentro del sitio web. Para esto es necesario un parámetro opcional en la función de inicialización (submenu) el cual recibirá el ID del submenú a desplegar.

Sidebar Submenú 
    /**
        Se envía un JSON de configuración con los IDs
        del nav, del sidebar y del submenú a desplegar.
    */
    let conf = {
        idNav: "#nav", // ID del nav
        idSidebar: "#sidebar", // ID del sidebar
        submenu: "#l1" // ID del submenú a desplegar
    }
    BS.SidebarDropInit(conf);

es importante aclarar que la personalización de este componente es muy amplia, permitiendo al usuario adaptar el sidebar a sus necesidades específicas.
Se recomienda ver las clases de fondo Colores y las clases de texto Tipografía para mejorar la visual predefinida.

 Información

Nótese que el sidebar drop de esta documentación se encuentra a su izquierda y es un ejemplo de todo lo que se puede lograr con este componente. Todas las personalización se las dejo al lector para que experimente y logre el diseño que mejor se adapte a su proyecto.

Destroy

En caso de que necesitemos desvincular la lógica del sidebar drop del nav podemos utilizar la función (Destroy) la cual no recibe parámetros y elimina todos los eventos asociados al sidebar drop. 

    /**
        Con esta función de desvincula la lógica del sidebar drop
        del nav asociado.
    */
    BS.SidebarDropDestroy();
