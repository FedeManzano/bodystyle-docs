📐 Flexbox

Bodystyle incluye una serie de clases CSS para facilitar el uso de Flexbox en tus proyectos web. Estas clases te permiten crear diseños flexibles y responsivos de manera sencilla.

Introducción

Bodystyle proporciona un conjunto de clases que permitirán utilizar la potente herramienta de flexbox de CSS, de manera tal que solo utilizando HTML podamos aplicar estos estilos y reacomodar los elementos de manera sencilla.
Flexbox permite distribuir el espacio entre los elementos de una interfaz y mejorar la alineación de los mismos y el reacomodamiento lateral y vertical de los elementos dentro de un contenedor, incluso cuando su tamaño es desconocido o dinámico.

Casos de Uso

A continuación se describen los casos de uso recomendados para cada clase de justificación:

.just-start - Alineación al Inicio

Cuándo usar: Cuando deseas que los elementos se alineen al inicio del contenedor (izquierda en dirección LTR). Ideal para listas de elementos, menús horizontales o formularios donde el contenido debe comenzar desde el lado izquierdo sin espacios adicionales.

Ejemplo: Menú de navegación, lista de botones de acción, breadcrumbs.

.just-center - Centrado

Cuándo usar: Cuando necesitas centrar los elementos en el contenedor. Es la opción perfecta para crear layouts simétricos, centrar iconos, logos o grupos de elementos para dar énfasis visual.

Ejemplo: Logo en el centro, botones principales centralizados, grupo de iconos de redes sociales.

.just-end - Alineación al Final

Cuándo usar: Cuando los elementos deben alinearse al final del contenedor (derecha en dirección LTR). Útil para botones de acción secundarios, botones de cerrar o elementos que deben estar al extremo derecho.

Ejemplo: Botón "Guardar" al lado derecho de un formulario, botón cerrar de un modal, navegación derecha.

.just-between - Espacio Entre Elementos

Cuándo usar: Cuando tienes dos o más elementos y deseas distribuirlos ocupando todo el ancho disponible, con el primer elemento al inicio y el último al final. Ideal para headers con logo en un extremo y menú en el otro.

Ejemplo: Header con logo a la izquierda y menú a la derecha, barra de utilidades con acciones separadas.

.just-around - Espaciado Alrededor

Cuándo usar: Cuando deseas distribuir los elementos con espacios iguales a su alrededor. Los elementos tendrán el mismo espacio antes y después de ellos. Perfecto para galerías, tarjetas de productos o cuando quieres que los elementos estén bien distribuidos visualmente.

Ejemplo: Galería de productos, filas de tarjetas, botones de opciones múltiples bien espaciados.

.just-center-m, .just-start-m, etc. - Responsive

Cuándo usar: Cuando necesitas que la justificación cambie según el tamaño de la pantalla. Combina diferentes clases (base, -m, -s, -xs) para adaptar el layout a cada dispositivo. Por ejemplo, elementos centrados en escritorio pero alineados al inicio en móviles.

Ejemplo: class="d-flex just-center just-start-m just-around-s" - Centra en desktop, inicio en tablet, distribuido en móvil.

 Consejo

La mejor práctica es combinar .just-center con .just-start-s o .just-start-xs para layouts más legibles en dispositivos móviles. De esta manera aprovechas mejor el espacio disponible en pantallas pequeñas.

Responsive

Todas las clases de alineación cuentan con variantes para cada tamaño de pantalla, permitiendo adaptar la alineación de los elementos según el dispositivo utilizado.

Clase Propiedad CSS Descripción
.ali-center-[m, s, xs] align-items: center Alinea los elementos al centro en el eje transversal en los diferentes tamaños de pantalla
.ali-start-[m, s, xs] align-items: flex-start Alinea los elementos al inicio en el eje transversal en los diferentes tamaños de pantalla

.ali-stretch-[m, s, xs] align-items: stretch Estira los elementos para llenar el contenedor en el eje transversal en los diferentes tamaños de pantalla
.ali-baseline-[m, s, xs] align-items: baseline Alinea los elementos según su línea base de texto en los diferentes tamaños de pantalla

 Información

Recuerda combinar las clases de alineación con las clases de justificación para lograr el diseño deseado en tus proyectos web. También es importante aclarar que las diferentes clases de alineamiento pueden ser aplicadas a un solo elemento en diferentes tamaños de pantalla, permitiendo una gran flexibilidad en el diseño responsivo.

Responsive

Todo las clases que vimos anteriormente se encuentran para todos los tipos de pantallas, permitiendo así una gran flexibilidad a la hora de diseñar layouts responsivos.
Por ejemplo, podemos utilizar la clase .flex-wrap-s para que el contenedor flexbox rompa la línea solamente en pantallas pequeñas.

Clase Propiedad CSS Descripción
.flex-wrap-[m, s, xs] flex-wrap: wrap; Permite romper el flexbox en los diferentes tamaños de pantalla
.flex-wrap-reverse-[m, s, xs] flex-wrap: wrap-reverse; Permite romper el flexbox en orden inverso en los diferentes tamaños de pantalla

Cambio de Ejes: Row vs Column

Información importante: Cuando usas .flex-column, los ejes principales y transversales se invierten. Esto significa que las propiedades justify-content y align-items afectan los elementos de manera opuesta.

Propiedad Con flex-row (defecto) Con flex-column
justify-content Alinea horizontalmente (eje principal) Alinea verticalmente (eje principal)
align-items Alinea verticalmente (eje transversal) Alinea horizontalmente (eje transversal)

Variantes Responsivas

Como con todas las clases de flexbox, .flex-column también tiene variantes responsivas para cambiar la dirección según el tamaño de pantalla:

Clase Descripción
.flex-column Columna en todos los tamaños de pantalla
.flex-column-m Columna en pantallas medianas y menores
.flex-column-s Columna en pantallas pequeñas
.flex-column-xs Columna en pantallas extra pequeñas

 Tip

Un patrón común es usar .flex-column-s para que el layout cambie a columna en dispositivos móviles, mejorando la legibilidad y experiencia de usuario en pantallas pequeñas.
