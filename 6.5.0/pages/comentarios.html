📝 Comentarios

Los comentarios son elementos dinámicos informativos que permiten gran cantidad de contenido, como texto, imágenes, videos, enlaces, listas, tablas y otros elementos HTML. Son ideales para mostrar información adicional sin sobrecargar la interfaz principal.
Es importante aclarar que este elemento al igual que los tooltips pertenecen a la dependencia Dynamics-Tips v3.0.0

Muestra

Ahora veremos una muestra de como añadir dinámicamente información a un elemento, por ejemplo un botón.
Nota: Los comentarios dinámicos pueden contener HTML, lo que permite una personalización avanzada del contenido mostrado.
Otra cosa importante es que la inicialización es automática al cargar la página, no es necesario llamar a ninguna función para que funcionen.

Posición

Es posible elegir la posición del comentario dinámico utilizando el atributo data-pos. Las opciones disponibles son: top, bottom, left, right, auto. Por defecto, la posición es bottom, lo que permite que el comentario se ajuste automáticamente según

Html

El contenido de los comentarios no necesariamente tiene que texto plano, puede contener HTML para una mejor presentación.

Evento Click

Por defecto los comentarios se activan al pasar el cursor sobre el elemento (hover), pero es posible configurarlos para que se activen al hacer click utilizando el atributo data-event="click".

Destroy

Es posible destruir un comentario dinámico utilizando el método BS.CommentDestroy() de esta forma todos los comentarios serán eliminados de la página. 

    function destroy() {
        BS.CommentDestroy();
        BS.Toast({
            html: "Comentarios destruidos",
            clases: ["bg-red", "c-white", "bor-pill"],
        })
    }
