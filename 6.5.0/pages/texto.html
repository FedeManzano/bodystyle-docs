 Advertencia

Nótese que en el ejemplo se utiliza la clase fz-[n] donde [n] representa el tamaño de la fuente en pixeles en todos los tamaños de pantalla, esto implica que lo definamos con esta clase se mantendrá constante sin importar el tamaño del dispositivo.
Además, esta forma de definición es general para todos los tamaños de dispositivos, esto implica que va a ser el mismo tamaño de fuente en móviles, tablets y escritorios.
Si lo que queremos es definir tamaños adaptables, en la siguiente sección se verán los tamaños responsive.

Tamaños Responsive

Es posible a través de la biblioteca Bodystyle definir tamaños de fuente responsive, es decir que cambien según el tamaño de pantalla del dispositivo.
utilizando los cuatro breakpoint documentados en Medidas podemos definir tamaños de fuente específicos para cada tamaño de pantalla.
A continuación se muestra un ejemplo de cómo definir tamaños de fuente responsive:

Texto que se ajusta (Achicar el ancho de la pantalla)

    

        
        
Texto que se ajusta (Achicar el ancho de la pantalla)
Clase Descripción
fz-[n] Define el tamaño de fuente para todos los dispositivos.
fz-m-[n] Define el tamaño de fuente para dispositivos medianos y más grandes (tablets y escritorios).
fz-s-[n] Define el tamaño de fuente para dispositivos pequeños y más pequeños (móviles y tablets).
fz-xs-[n] Define el tamaño de fuente para dispositivos extra pequeños (móviles).

Sass Modificación

Si está utilizando Bodystyle a través de Sass, puede personalizar los estilos de las cabeceras modificando las variables correspondientes en su archivo Sass antes de compilar. Esto le permite adaptar las cabeceras a las necesidades específicas de su proyecto. 

    h1,
    .h1 {
      font-size: 2em;
      font-weight: 600;
    }

    h2,
    .h2 {
      font-size: 1.6em;
      font-weight: 500;
    }

    h3,
    .h3 {

Line Height

La altura de línea (line height) es un aspecto crucial en el diseño tipográfico, ya que afecta la legibilidad y la apariencia general del texto. Bodystyle proporciona clases específicas para ajustar la altura de línea de los textos de manera sencilla y efectiva. En este caso la clase ln-[n] donde n es la altura del interlineado permite ajustar esta propiedad para (todos los tamaños de pantalla).
