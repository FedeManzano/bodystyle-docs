Texto

En esta sección daremos ejemplos concretos sobre todas las funcionalidades que acompañar al texto, un conjunto de clases que permitirán mejorar la presentación del mismo.
A continuación se muestra una tabla de ejemplo para ilustrar el uso de las tablas en Bodystyle.

Alineación

Existen clases dentro de Bodystyle que permiten alinear el texto a la derecha, a la izquierda o al centro según sea necesario. A continuación se muestran ejemplos de cada una de estas clases:

Esto es un texto alineado a la izquierda. (clase: .ta-l)
Esto es un texto alineado a la derecha. (clase: .ta-r)
Esto es un texto alineado a la centrado. (clase: .ta-c)

 Información

Para poder definir estos ejemplos se utilizaron las clases de .ta-l, .ta-r y .ta-c respectivamente y las clases de alineamiento como el p-[n] y colores de texto.

.c-[nombre del color]
