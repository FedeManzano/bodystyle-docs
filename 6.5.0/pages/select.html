🔽 Select

El elemento <select> es un componente de formulario que permite a los usuarios seleccionar una opción de una lista desplegable. Es útil cuando se desea limitar las opciones disponibles para el usuario y garantizar que solo se seleccione una opción válida.

 Información

Para poder utilizar este elemento es necesario incluír la lógica de Bodystyle a través de su archivo JavaScript. Luego, es necesario inicializar el componente utilizando la función de inicialización que apunta al ID del contenedor que envuelve al elemento <select>. 

    
    
 
        
    


    // Inicialización del componente Select
    // Esta función devuelve una instancia del componente Select
    // La cual permitirá inicializarlo, y además si en la página hay varios select 
    // se podrán inicializar todos de forma independiente
    BS.SelectInit().iniciar("#id", "borde");

    // Otra forma sería de la siguiente manera:
    const miSelect = BS.SelectInit();
    miSelect.iniciar("#id", "borde"); // Nótese que el ID lleva el #
    // Sin el # no va a funcionar

 Tema Claro

A continuación se muestra un ejemplo de un elemento <select> con varias opciones en tema claro: 

    
    
 
        
    


    const miSelectClaro = BS.SelectInit();
    miSelectClaro.iniciar("#id-claro", "borde");

    /* Si queremos destruirlo simplemente llamamos al metodo destroy*/
    miSelectClaro.destroy("#id-claro"); // Desvinculando y limpiando los eventos asociados

Efecto Fondo

Hasta ahora vimos el efecto borde en los elementos Select anteriores, es posible en la función de inicialización establecer el efecto hover fondo, para generar una estética diferente. A continuación se muestra un ejemplo: 

    
 
        
    


    const miSelectFondo = BS.SelectInit();
    miSelectFondo.iniciar("#id-fon", "fondo");

Ejemplo con Localidades 🔽

A continuación se muestra un ejemplo más realista con una lista completa de localidades: 

    

        
    


    const miSelectLocalidades = BS.SelectInit();
    miSelectLocalidades.iniciar("#id-localidades", "borde");

Destruir

Como se mencionó anteriormente es posible destruir el elemento desvinculando la lógica que lo maneja y limpiando los eventos asociados. Esto se logra llamando al método destroy de la instancia del componente Select. 

    
    


    // Función para destruir los select
    function destroy () {
        BS.SelectInit().destroy("#idselect");
        BS.SelectInit().destroy("#id-light");
        BS.SelectInit().destroy("#id-fondo");
        BS.SelectInit().destroy("#id-localidades");

        /** Mostrar un toast de confirmación */
        // Documentado en la sección correspondiente a Toast
        BS.Toast({
            html: "Todos los select destruidos",
            clases: ["bg-red", "bor-rad-10", "c-white"],
            tiempo: 3000,
            cerrar: true
        })
    }
