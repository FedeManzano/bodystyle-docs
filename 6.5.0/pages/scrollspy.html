📌 ScrollSpy

El componente ScrollSpy permite crear una barra de navegación que resalta automáticamente los enlaces correspondientes a las secciones visibles en la ventana gráfica mientras el usuario se desplaza por la página. Esto facilita la navegación y mejora la experiencia del usuario al proporcionar un acceso rápido a diferentes secciones del contenido.

Inicialización

Para inicializar el componente ScrollSpy, asegúrate de que tu barra de navegación y las secciones objetivo tengan los atributos y clases necesarios. La barra de navegación debe contener enlaces con referencias a las secciones mediante IDs.

Parámetro Valor Descripción Default Obligatorio
ancho 1-100% Ancho del scrollspy en porcentaje 16 NO
tamFuente 1-30px Tamaño de la fuente del scrollspy en píxeles 16 NO
colorBorde fd-color Color del borde del scrollspy (Clases de Bodystyle) fd-azul NO
alturaBorde 1-100px Altura del borde del scrollspy en píxeles 3 NO
separacion 1-n (px) Separación entre el scrollspy y el inicio de la página en píxeles 100 NO
colorSeleccionado Hexadecimal Color del elemento seleccionado en el scrollspy #000 NO
colorNoSeleccionado Hexadecimal Color del elemento no seleccionado en el scrollspy #666 NO

 Peligro

Este componente no es compatible con el efecto Reveal si se usan ambos puede generar comflictos que no permitan su buen funcionamiento.

    let conf = {
        ancho: 16, // Ancho en %
        tamFuente: 18, // Tamaño de fuente en px
        colorBorde: "fd-bodyui", // Clase de Bodystyle para el color del borde
        alturaBorde: 35, // Altura del borde en px
        separacion: 150, // Separación desde el tope de la página en px
        colorSeleccionado: "#222", // Color del elemento seleccionado
        colorNoSelecccionado: "#666" // Color del elemento no seleccionado
    }
    BS.ScrollSpyInit(conf)

Ocultar

Por lo general este elemento se utiliza en equipos de pantalla grande (mayores a 1030px) pero en equipos de tamaños infereriores se opta por ocultarlo ya que interfiere en ell flujo de la página y la experiencia del usuario. Para ello se le agrega la clase ocultar-desde-medianos al contenedor del scrollspy.
