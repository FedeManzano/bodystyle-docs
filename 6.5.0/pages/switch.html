Los switches son elementos interactivos que permiten a los usuarios activar o desactivar una opción específica en una interfaz de usuario. Funcionan como interruptores físicos, proporcionando una forma intuitiva de controlar configuraciones o funciones dentro de una aplicación o sitio web.

Muestra

Los switches conformados por un input chackbox y un label que acompaña asociado al input antes mencionado conforma un elemento que permite establecer un estado de activado o desactivado. 

    

    

        
        
    
 

    document.getElementById("boton").addEventListener("change", function() {
        if (this.checked) {
            document.getElementById("btn").classList.remove("desactivado");
            console.log("El switch está activado");
        } else {
            document.getElementById("btn").classList.add("desactivado");
            console.log("El switch está desactivado");
        }
    });

            document.getElementById("color").classList.remove("bg-blue");
            document.getElementById("color").classList.add("bg-red");
            document.getElementById("color").textContent = "Esto es un div ROJO";
            console.log("El switch está desactivado");
        }
    });

Es importante aclarar que el atributo for del label debe coincidir con el id del input para que el switch funcione correctamente.

Switch Desactivado

Los switches pueden ser desactivados usando el atributo disabled en el input. Esto impide que el usuario interactúe con el switch.
