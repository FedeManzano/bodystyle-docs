🖥️ Display

Los display en Bodystyle permiten controlar la visibilidad y el comportamiento de los elementos en la página web. Estos display son esenciales para crear diseños responsivos y adaptativos, asegurando que los contenidos se muestren correctamente en diferentes dispositivos y tamaños de pantalla.
Esta sección es introductoria a la sección de Flexbox y la grilla Grilla.

Display Block

El display block es un tipo de visualización que hace que un elemento ocupe todo el ancho disponible de su contenedor, comenzando en una nueva línea. Los elementos con display block son ideales para estructuras de contenido como párrafos, encabezados y divs, ya que permiten organizar el contenido de manera clara y legible.

Clase Medida Descripción
.d-block Todos los dispositivos Permite definir un elemento como bloque en todos los tamaños de dispositivos.
.d-block-m Medianos (768px a 1031px) Permite definir un elemento como bloque en dispositivos medianos.
.d-block-s Pequeños (400px a 767px) Permite definir un elemento como bloque en dispositivos pequeños.
.d-block-xs Extra pequeños (menos de 400px) Permite definir un elemento como bloque en dispositivos extra pequeños.

 Comparación: Block vs Inline vs Inline-Block

Es importante entender las diferencias entre los distintos tipos de display para elegir el correcto según tus necesidades:

Propiedad Block Inline Inline-Block
Ancho Ocupa 100% del ancho disponible Solo el ancho necesario Solo el ancho necesario
Altura (height) Se respeta el valor height Se ignora el valor height Se respeta el valor height
Margen (margin) Se aplica en todos los lados Solo left y right Se aplica en todos los lados
Padding (padding) Se aplica en todos los lados Se aplica en todos los lados Se aplica en todos los lados
Nueva línea Sí, siempre comienza en una nueva línea No, fluye en línea con otros elementos No, fluye en línea con otros elementos
Ejemplo <div>, <p>, <h1> <span>, <a>, <strong> Combinación de block e inline

 Margin Collapse (Colapso de Márgenes)

El margin collapse es un comportamiento especial de los elementos con display block donde los márgenes verticales (top y bottom) se fusionan cuando dos elementos están adyacentes, utilizando el valor mayor en lugar de sumarlos. Este es un concepto importante a entender para evitar espaciados inesperados.

 ¿Cuándo ocurre el margin collapse?

  • Entre un elemento padre y su primer/último hijo
  • Entre elementos hermanos bloques adyacentes
  • En elementos vacíos (solo margen top y bottom)

Ejemplo 1: Colapso entre hermanos

En este ejemplo, dos divs con márgenes de 20px. Normalmente esperaríamos 40px de espacio, pero el margin collapse hace que sea solo 20px (el valor mayor):

    function block() {
        const test = document.getElementById("test");
        test.classList.remove("d-flex");
        test.classList.remove("d-inline-block");
        test.querySelectorAll("div").forEach(div => {
             div.classList.remove("d-inline");
        });
        test.classList.add("d-block");
    }


    function inline() {
        const test = document.getElementById("test");
        test.classList.remove("d-flex");
        
        test.querySelectorAll("div").forEach(div => {
            div.classList.add("d-inline");
        });
        test.classList.remove("d-inline-block");
        test.classList.remove("d-block");
    }


    function inblock() {
        const test = document.getElementById("test");
        test.classList.remove("d-flex");
        test.classList.add("d-inline-block");
        test.querySelectorAll("div").forEach(div => {
             div.classList.remove("d-inline");
        });
        test.classList.remove("d-block");
    }


    function flex() {
        const test = document.getElementById("test");
        test.classList.add("d-flex");
        test.classList.remove("d-inline-block");
        test.querySelectorAll("div").forEach(div => {
             div.classList.remove("d-inline");
        });
        test.classList.remove("d-block");
    }
