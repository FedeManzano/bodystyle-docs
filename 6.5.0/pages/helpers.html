Helpers

Los helpers son una serie de funciones auxiliares que permiten ajustar la visibilidad y comportamiento de elementos en el DOM de manera sencilla y eficiente.

Introducción

Los helpers en Bodystyle son funciones diseñadas para facilitar tareas comunes relacionadas con la manipulación del DOM. Estos helpers permiten mostrar u ocultar elementos, alternar clases CSS, y realizar otras operaciones útiles que mejoran la interactividad y la experiencia del usuario en una página web.
Recomendación: Ver la página donde se describen los Breakpoint utilizados por Bodystyle desde Medidas.

SASS

Con las propiedades y funciones de SASS se crearon estos helpers para facilitar la tarea de mostrar u ocultar elementos según el tamaño de pantalla. 

    /**
       Estos mixin son la base de los helpers de visibilidad de Bodystyle.
       A partir de ellos se ajustará la visibilidad delos elementos según
       el tamaño de pantalla.
    */


    /**
        Este mixin permite agregar estilos CSS a medida que el tamaño de pantalla
        sea menor o igual al tamaño seleccionado.
    */
    @mixin agregar-a-medida-maxima($tam) {
        @if map.has-key(variables.$tamaños, $tam) {
            @media (max-width: #{map.get(variables.$tamaños, $tam)}) {
                @content;
            }
        }

        @else {
            @warn "El tamaño seleccionado no existe";
        }
    }

    /**
        Este mixin permite agregar estilos CSS a medida que el tamaño de pantalla
        sea mayor o igual al tamaño seleccionado.
    */
    @mixin agregar-a-medida-minima($tam) {
        @if map.has-key(variables.$tamaños, $tam) {
            @media (min-width: #{map.get(variables.$tamaños, $tam)}) {
                @content;
            }
        }

        @else {
            @warn "El tamaño seleccionado no existe";
        }
    }

Luego, con las clases apropiadas y utilizando estos mixin podemos establecer de manera sencilla cada uno de los helpers. 

    @use "../globales/mixins";

    /**
        Helpers de visibilidad de elementos según tamaño de pantalla
    */
    .ocultar-solo-grandes,
    .hide-only-large {
        @include mixins.agregar-a-medida-minima(m) {
            display: none !important;
        }
    }

    /// Ocultar desde pantallas medianas hacia abajo
    .ocultar-desde-medianos,
    .hide-from-medium {
        @include mixins.agregar-a-medida-maxima(m) {
            display: none !important;
        }
    }

    /// Ocultar desde pantallas chicas hacia abajo
    .ocultar-desde-chicos,
    .hide-from-small {
        @include mixins.agregar-a-medida-maxima(s) {
            display: none !important;
        }
    }

    /// Ocultar desde pantallas extra chicas hacia abajo
    .ocultar-desde-x-chicos,
    .hide-from-x-small {
        @include mixins.agregar-a-medida-maxima(xs) {
            display: none !important;
        }
    }

    /// Mostrar solo en pantallas extra chicas
    .mostrar-solo-x-chicos,
    .show-only-x-small {
        @include mixins.agregar-a-medida-minima(xs) {
            display: none !important;
        }
    }

    /// Mostrar solo en pantallas chicas
    .mostrar-solo-chicos,
    .show-only-small {
        @include mixins.agregar-a-medida-minima(s) {
            display: none !important;
        }

        @include mixins.agregar-a-medida-maxima(xs) {
            display: none !important;
        }
    }

    /// Mostrar solo en pantallas medianas
    .mostrar-solo-medianos,
    .show-only-medium {
        @include mixins.agregar-a-medida-minima(m) {
            display: none !important;
        }

        @include mixins.agregar-a-medida-maxima(s) {
            display: none !important;
        }
    }

    /// Mostrar solo en pantallas grandes
    .mostrar-solo-grandes,
    .show-only-large {
        @include mixins.agregar-a-medida-maxima(m) {
            display: none !important;
        }
    }
