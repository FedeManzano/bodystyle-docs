🖌️ Decoradores

Los decoradores son elementos visuales que permiten mejorar la estética de los títulos en una página web. Estos elementos pueden ser líneas, formas o iconos que se colocan alrededor o cerca del título para darle un aspecto más atractivo y profesional.

Sass

Si estamos trabajando desde el repositorio de Bodystyle y utilizando Sass, podemos encontrar las variables relacionadas con los decoradores en el archivo "_header_decorator.scss". Aquí podemos personalizar los colores y modificar los estilos que se ajusten al proyecto en desarrollo. 


/*
    Importa las variables globales de bodystyle
    Estos colores afectan a todos los elementos que utilizan
    estos colores en bodystyle.
*/
@use "globales/variables";


/** Con esto aumentamos la separación del decorador respecto al contenido */
.bs-header-decorator {

    padding-bottom: 12px;
}

/** Desde estas variables podemos modificar los colores a través de variables globales */
$rojo: linear-gradient(90deg, variables.$fd-rojo 0%, #ff000000 100%);
$azul: linear-gradient(90deg, variables.$fd-azul 0%, #ff000000 100%);
$verde: linear-gradient(90deg, variables.$fd-verde 0%, #ff000000 100%);
$gris: linear-gradient(90deg, variables.$fd-gris 0%, #ff000000 100%);
$negro: linear-gradient(90deg, variables.$fd-negro 0%, #ffffff00 100%);
$blanco: linear-gradient(90deg, variables.$fd-blanco 0%, #ffffff00 100%);

        border-radius: 99999px;
        position: absolute;
        bottom: 0;
        right: 0;
        left: 0;
        height: 5px;
        background: $rojo;

Uso Recomendado

En páginas visualmente atractivas o profesionales, como portafolios, blogs de diseño o sitios web corporativos, el uso de decoradores en los títulos puede mejorar significativamente la apariencia general y captar la atención del usuario.

Color Uso Recomendado Contexto
Rojo Alertas, advertencias, secciones importantes o llamadas a la acción críticas Errores, promociones urgentes, títulos destacados
Azul Información general, secciones principales, confiabilidad y profesionalismo Encabezados de secciones, títulos de artículos, headers principales
Verde Éxito, confirmación, progreso positivo o contenido relacionado con naturaleza Mensajes de éxito, secciones completadas, tips útiles
Gris Subtítulos, secciones secundarias, contenido menos importante Descripciones, texto de ayuda, secciones auxiliares
Negro Elegancia, minimalismo, diseños oscuros o profesionales Portafolios de diseño, sitios corporativos, interfaces modernas
Blanco Sobre fondos oscuros, diseños con tema oscuro (dark mode) Interfaces dark mode, secciones sobre fondos de color

 Consejo

Para mejores resultados, mantén la consistencia en tu diseño. Asigna cada color a un tipo de contenido específico en toda tu página web. Por ejemplo, usa siempre rojo para advertencias y azul para títulos principales. Esto ayuda a los usuarios a reconocer patrones visuales.
