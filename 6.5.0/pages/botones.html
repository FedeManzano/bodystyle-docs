📥 Botones

En este apartado trataremos sobre los botones que ofrece Bodystyle. Los botones son elementos interactivos que permiten a los usuarios realizar acciones al hacer clic en ellos. Bodystyle proporciona una variedad de clases CSS para personalizar la apariencia y el comportamiento de los botones.

Default

A continuación se muestra los botnes por default junto con el botón Desactivado que remueve todos los atributos de comprtamiento de manera automática.

 Información

El botón desactivado remueve todos los atributos del botón, por lo que no responderá a ningún evento de usuario.
Si dinámicamente removemos la clase .desactivado los atributos y comportamientos del botón volverán a la normalidad.

Colores

Para colorear un botón debes combinar tres clases:

  • .btn - Clase base del botón
  • .[bg | fd]-[color] - Color de fondo (ej: bg-red, bg-green, etc)

Estructura: <button class="btn bg-color">Botón</button>

La paleta de colores disponibles se encuentra documentada en la sección de Colores. Cada color tiene variantes: el color base, -s (soft/claro) y -d-1 (dark/oscuro).

 Información

Colores de fondo: Usa .bg-[color] o .fd-[color] para colorear el fondo
Consulta la sección de Colores para ver todas las opciones disponibles.

Tamaños

Bodystyle maneja tres tamaños (sm | md(default) | lg) para los botones.
Cada una de ella utiliza la clase .btn-[size] donde size puede ser sm para pequeño, N/A para mediano (Default) y lg para el grande.

  • .btn-sm - Para botones pequeños
  • .btn - Para botones medianos (Default)
  • .btn-lg - Para botones grandes

Efecto Waves

Es posible añadir un efecto al botón al momento de hacer click en él, similar al efecto "waves" que se encuentra en otros frameworks. Para ello, simplemente debemos añadir la clase .waves al botón.

 Advertencia

El efecto waves se inicializa automáticamente en proyectos tradicionales, lo único que hay que tener en cuenta es tenés vinculado el archivo bodystyle.bundled.js en tu proyecto.
En proyecto SPA (Single Page Application) es necesario inicializar el efecto de manera manual utilizando la función BS.WavesInit() después de cargar los nuevos contenidos dinámicamente.

Link

Los enlaces son elementos fundamentales para la navegación. Bodystyle proporciona la clase .link que aplica un estilo especial a los enlaces, incluyendo efectos al pasar el cursor y soporte para combinaciones de colores.

Características:

  • Efecto hover suave y profesional
  • Con las clases .btn .fd-color conseguimos el mismo resultado que con los botones.
  • Subrayado animado al pasar el cursor
  • Optimizado para accesibilidad

 Información

Los enlaces con clases de botón (.btn .fd-color) ofrecen una apariencia similar a los botones, pero mantienen la funcionalidad de un enlace.
Esto es útil para crear enlaces que se destaquen visualmente y sean fáciles de identificar como interactivos.

Botones Outline

Los botones outline tienen un estilo diferente: presentan un borde definido con fondo transparente, dando una apariencia más ligera y moderna. Son ideales para acciones secundarias o botones menos relevantes.

Estructura de clases:

  • .btn-o - Clase base para outline
  • .btn-color-o - Color del botón (disponibles: bodyui, green, blue, black, grey, white)

Estructura: <button class="btn-o btn-red-o">Outline</button>

Colores Disponibles

Tamaños de Botones

Los botones en Bodystyle tienen tres tamaños disponibles: pequeño, medio y grande. Las clases varían dependiendo del estilo (relleno u outline).

  • btn-sm-o - Botón pequeño
  • btn-o - Botón medio (default)
  • btn-lg-o - Botón grande

Botones 100%

Tanto los botones llenos como los botones outline pueden ocupar el 100% del ancho de su contenedor padre. Para lograr esto, simplemente debemos añadir la clase .btn-cover al botón.

Outline 100%

Con los botones outline es similar al caso anterior, simplemente debemos añadir la clase .btn-cover junto con las clases de outline.

Border Pill

Utilizando un clase de las pertenecientes a los bordes, es posible darle a los botones un estilo "pill" (pastilla), que les da bordes redondeados para una apariencia más suave y moderna.

Botón Pill

Para lograr esto simplemente añadimos la clase .bor-pill al botón. 

    
    
Botón Pill

 Información

La clase .bor-pill puede combinarse con cualquier estilo de botón (relleno u outline) para lograr el efecto deseado.
