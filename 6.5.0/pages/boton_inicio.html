Botón Inicio

El botón de inicio es un componente interactivo que permite a los usuarios volver rápidamente a la parte superior de una página web con un solo clic. Este botón suele aparecer cuando el usuario desplaza la página hacia abajo, proporcionando una forma conveniente de regresar al inicio sin tener que desplazarse manualmente.

Inicialización

Para utilizar este elemento lo único que tendremos que tener en cuenta es disponer del archivo bodystyle.min.js y luego inicializar el boón de inicio a través del objeto BS.BotonInicioInit() de la siguiente manera: 

    // Inicializar el botón de inicio
    BS.BotonInicioInit() // Aparece automáticamente al hacer scroll

Destroy

Es posible liberar recuros destruyendo el componente con la función BS.BotonInicioDestroy() de la siguiente manera: 

    // Destruir el botón de inicio
    BS.BotonInicioDestroy() // Libera recursos y oculta el botón
