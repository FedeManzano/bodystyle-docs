😊 Formas

Bodystyle incluye una serie de clases CSS para crear diferentes formas y figuras geométricas utilizando solo CSS. Estas clases permiten crear círculos, óvalos, triángulos, estrellas y otras formas personalizadas de manera sencilla y rápida.
