ℹ️ Información

¿Cómo funciona?

Este sistema usa Web Workers para hacer búsquedas sin bloquear la interfaz. Características:

  • ✨ Búsqueda no-bloqueante (en otro thread)
  • 🎯 Resultados ordenados por relevancia
  • ⌨️ Debounce automático (espera 300ms)
  • 📊 Indicador de carga
  • 🔍 Búsqueda en título y tags

Prueba rápida:

  1. Vuelve a la pestaña "Prueba"
  2. Escribe en el input
  3. Verás resultados aparecer sin congelarse
  4. Prueba escribir más palabras para ver más resultados
