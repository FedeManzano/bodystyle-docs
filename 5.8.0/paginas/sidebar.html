Sidebar

Elemento que es manejado por la barra de navegación principal a través el botón de menú, que a través de las clases pertinentes toma la forma de las tres barras acostadas y sirve como disparador para desplegar el sidebar.

Inicialización

Para inicializar el sidebar primero tenemos que iniciallizar el nav principal que es el que va a controlar la barra lateral.
es importante recalcar que si ambos elementos (nav y el sidebar) se añaden al html de forma dinámica (se agregan al html en tiempo de ejecución) es necesario iniciar el componente de otra forma, tal y como se describe debajo de este texto. 

    // Forma 1: Tradicional (No dinámica)
    BS.NavigationInit("#ID") // Donde ID es el ID del nav principal 

    // Forma 2: Dinámica 
    window.onload = () => setTimeout( () => BS.NavigationInit("#ID"), 100)

Responsive

Otra forma de utilizar el sidebar es para reemplazar las opciones del menu del nav. Para dispositivos de tamaño de pantalla más pequeños ocultamos el menú del NAV y lo reemplazamos por del sidebar.
Para realizar esta tarea no apoyaremos en los Helpers.
