Desactivado

Funcionalidades que desvinculan los eventos asociados a los elementos y cambia su apariencia para mostrarle al usuario que temporalmente esos elementos no están activos.
En sitios dinámicos es ncesario disponer de la capacidad de apagar un elemento en determinadas circunstancias y es por ello que utilizaremos la clase .desactivado.

Muestra de Elementos

Para clarificar de lo que trata esta sección de la documentación le aplicaremos la clase .desactivado a un botón, un enlace y un input.

Enlace Desactivado
Utilizando esta clase e incluyendo el archivo de js de la librería antes de la finalización de la etqueta html body se consigue anular completamente el elemento afectado por la clase .desactivado.

Código del Módulo

Para poder explicar mejor que realiza el módulo lo mejor es ver el código fuente que lleva a cabo esta tarea. 

    import $ from 'jquery'
    /**
     * Módulo (11) Se encarga se retirarle todos los eventos html
     * a los elementos que contengan la clase .desactivado.
     * Módulo que se inicializa de manera automática, sin necesidad de llamar a 
     * la función de inicialización. 
     */
    (function(){

        const inicializar = () => {
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onclick"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("ondblclick"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onmousedown"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onmouseleave"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onmouseout"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onkeydown"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onkeypress"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onkeyup"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("href"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onfocus"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onblur"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onchange"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onselect"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onreset"))
            document.querySelectorAll(".desactivado, .desactivado *").forEach(el => el.removeAttribute("onsubmit"))
            document.querySelectorAll("input.desactivado").forEach(el => el.setAttribute("readonly", true))
            document.querySelectorAll("*.desactivado *").forEach(el => el.setAttribute("readonly", true))
            document.querySelectorAll("*.desactivado *").forEach(el => el.classList.add("desactivado"))
            document.querySelectorAll("input.desactivado").forEach(el => { const label = el.previousElementSibling?.tagName === "LABEL" ? el.previousElementSibling : el.nextElementSibling; if (label?.tagName === "LABEL") label.removeAttribute("for"); })
        }

        var Desactivado = {
            iniciar: () => {
                inicializar();
            }
        }
        window.Desactivado = Desactivado
    })()

    export default Desactivado
Esta funcionalidad se puede aplicar a cualquier elemento del dom, removiendo todos los eventos asociados a este elemento, y temporalmente dejandolo inhabilitado.
